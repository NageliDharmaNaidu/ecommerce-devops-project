# E-Commerce DevOps Project

> A full-stack e-commerce project used to practice containerization, CI/CD, Kubernetes and cloud deployment concepts.

## 🎯 Overview

This repository brings application development and DevOps practices together:

- React frontend
- Node.js / Express backend
- Database-backed services
- Docker containerization
- Kubernetes deployment manifests
- Jenkins CI/CD pipeline configuration
- AWS deployment examples

## 🛠️ Stack

| Area | Tools |
|---|---|
| Frontend | React, HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Databases | MySQL, MongoDB |
| Cache | Redis |
| Containers | Docker |
| Orchestration | Kubernetes |
| CI/CD | Jenkins, GitHub |
| Cloud | AWS |
| Version Control | Git, GitHub |

## 🔄 DevOps Flow

```
GitHub → Jenkins → Build → Test → Docker Image → Kubernetes → Deployment
```

## 📁 Key Areas

- `frontend/` — client application
- `backend/` — API and business logic
- `docker/` — container configuration
- `kubernetes/` — deployment and service manifests
- `jenkins/` — CI/CD pipeline configuration
- `.github/workflows/` — GitHub Actions examples
- `docs/` — architecture and deployment notes

## 🚀 What This Project Demonstrates

- Building and packaging applications with Docker
- Designing Kubernetes deployment resources
- Automating build/test/deploy workflows
- Working with cloud deployment concepts
- Keeping infrastructure and application configuration version-controlled
